BiliBili 直播取流 [M3U8]

Posted on Feb 8, 2026

在 Web 平台上，BiliBili 使用 HLS 协议，提供一个动态刷新的 m3u8 文件以实现直播流的传输。主引索文件可以 通过发送附带cid和mid参数的请求获得。

cid: 直播间长 ID

mid: 主播 ID

[GET] https://api.live.bilibili.com/xlive/play-gateway/master/url?cid=<cid>&mid=<mid>

#EXT-X-MAP:URI="h1770531613.m4s"作为初始化片段将不会变化，用于提供元数据。

列表内的直播流无法单独播放，需在第一次请求时将初始化片段与列表的直播流拼接，在后续的请求中向末尾追加列表中新的直播流。

列表只储存了文件名；在用于获此子 m3u8 文件的链接中，可以找到完整请求所需的地址。

https://d1--cn-gotcha204b.bilivideo.com/live-bvc/789996/live_690608693_5023542_bluray/index.m3u8?...

live_690608693_5023542_bluray中的_bluray表示这是一个质量为原画的 m3u8 文件(qn = 10000)；相应的，蓝光(qn = 400)的标识为_4000，超清(qn = 250)为_2500

⚡️ Notice
原画不只有 _bluray 这一个后缀，今天发现 _39901278 也会出现在原画的链接中

最后，用上述地址拼接与文件名后发送请求，即可获取一个直播流片段。

wget -O part.m4s 'https://d1--cn-gotcha204b.bilivideo.com/live-bvc/789996/live_690608693_5023542_bluray/1770539728.m4s'

用cat在初始化片段后追加新的直播流

cat h1770531613.m4s 17705397*.m4s  > output.m4s
